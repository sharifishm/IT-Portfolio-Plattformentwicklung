# Virtualisierung mit Oracle VirtualBox & Ubuntu

**Schulprojekt | Modul 187**

**Ausbildung:** Informatiker EFZ Plattformentwicklung

## Projektübersicht

Im Rahmen meiner Ausbildung zum Informatiker EFZ Plattformentwicklung habe ich mich mit der Virtualisierung und der Installation von Linux-Betriebssystemen beschäftigt.

Dabei habe ich mit Oracle VirtualBox gearbeitet und Ubuntu Desktop sowie Ubuntu Server als virtuelle Maschinen installiert.

Ziel war es, praktische Erfahrungen im Umgang mit virtuellen IT-Umgebungen, Betriebssysteminstallationen und grundlegenden Administrationsaufgaben zu sammeln.

## Praktische Arbeiten

**1. Virtualisierung und Installation**
- Virtuelle Maschinen mit Oracle VirtualBox erstellt
- Ubuntu Desktop und Ubuntu Server installiert
- Arbeitsspeicher, CPU-Kerne und virtuelle Festplatten konfiguriert
- ISO-Dateien als Installationsmedium verwendet
- Start- und Konfigurationseinstellungen überprüft

**2. Linux und Systemverwaltung**
- Grundlagen der Linux-Kommandozeile angewendet
- Mit Dateien, Verzeichnissen und Systembefehlen gearbeitet
- Ubuntu-Systemkonfigurationen untersucht
- Systemaktualisierungen und Paketverwaltung mit APT behandelt

**3. Netzwerk und Remote-Zugriff**
- Grundlagen von SSH und verschlüsselten Terminalverbindungen kennengelernt
- Remote-Zugriff mit PuTTY eingerichtet und erprobt
- NAT und Portweiterleitung in VirtualBox behandelt
- Netzwerk- und Verbindungsprobleme untersucht

**4. Fehleranalyse**
- Start- und Konfigurationsprobleme virtueller Maschinen untersucht
- Linux-Terminalfehlermeldungen analysiert
- Mögliche Fehlerursachen eingegrenzt und Lösungswege erarbeitet

## Eingesetzte Technologien

| Technologie | Einsatzbereich |
|---|---|
| Oracle VirtualBox | Virtualisierung und VM-Konfiguration |
| Ubuntu Desktop | Linux-Betriebssystem |
| Ubuntu Server | Virtuelle Serverumgebung |
| Linux-Terminal / Bash | Grundlegende Systembefehle |
| PuTTY / SSH | Remote-Zugriff und Verbindungsversuche |
| APT | Grundlagen der Paketverwaltung |
| NAT | Virtuelle Netzwerkkonfiguration |

## Ergebnis und Lernerfahrungen

Durch das Projekt konnte ich meine Grundlagen in der Virtualisierung und Linux-Systemverwaltung erweitern.

Besonders wertvoll waren die praktischen Arbeiten mit virtuellen Maschinen sowie die Untersuchung technischer Probleme.

Dabei habe ich gelernt, wie virtuelle IT-Systeme aufgebaut sind, welche Ressourcen sie benötigen und wie man bei Konfigurations- und Startproblemen systematisch vorgeht.
