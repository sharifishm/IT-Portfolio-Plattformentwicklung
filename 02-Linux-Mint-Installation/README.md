# Linux Mint – Installation auf einem externen Datenträger

**Projektart:** Privates IT-Projekt (Freizeit)

**Bereich:** Linux | Betriebssysteme | Datenträgerverwaltung

## Projektbeschreibung

Im Rahmen meines persönlichen Interesses an Informatik und Linux habe ich eigenständig Linux Mint auf einem externen Datenträger installiert und eingerichtet.

Ziel des Projekts war es, praktische Erfahrungen mit der Installation eines Linux-Betriebssystems sowie der Partitionierung und Verwaltung von Datenträgern zu sammeln.

## Durchführung

- Vorbereitung eines externen Datenträgers mit 2 TB Speicherkapazität
- Partitionierung in zwei Speicherbereiche mit jeweils ungefähr 1 TB
- Installation von Linux Mint auf dem vorgesehenen Speicherbereich
- Einrichtung und Inbetriebnahme des Linux-Betriebssystems
- Überprüfung der grundlegenden Systemfunktionen

## Eingesetzte Technologien

- Linux Mint
- Linux-Betriebssystem
- Datenträgerpartitionierung
- Dateisystemverwaltung

## Ergebnis

Die Installation von Linux Mint wurde erfolgreich abgeschlossen. Das Betriebssystem funktioniert einwandfrei und der externe Datenträger wurde entsprechend der geplanten Speicheraufteilung eingerichtet.

## Erworbene Kenntnisse

Durch dieses eigenständige Projekt konnte ich meine Kenntnisse in folgenden Bereichen erweitern:

- Installation und Einrichtung von Linux-Betriebssystemen
- Grundlagen der Partitionierung und Speicherverwaltung
- Verständnis der Datenträgerstruktur
